CarSage estimates the resale price of a used car and gives a likely price range, for example "₹4.2 lakh, likely between ₹3.6 and ₹4.9 lakh". It uses NVIDIA Kumo Tabular, a tabular foundation model that predicts from labeled examples in a single forward pass, with no training, tuning, or feature engineering. The project includes a Streamlit web app, a comparison against an XGBoost baseline, and a check of how well the price range covers real prices. You can also add new sales to the context and see the model adapt without retraining.
